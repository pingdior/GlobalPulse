1. 软件定位与核心价值
产品名称（暂定）： GlobalPulse AI (全球脉动)

Slogan： 穿透信息茧房，解码全球情绪。

核心定位： 针对出海创业者、创作者及研究者的“全球舆情敏锐度”放大器。它不仅告诉你“发生了什么”，更告诉你“为什么引爆”以及“各地区反应的差异”。

2. 功能模块补充与优化
功能 1：多维全球情报网 (优化：增加翻译与源解析)
优化点： 增加**“实时自动翻译”和“源媒体权重分析”**。

细化：

7大地区覆盖： 针对不同地区抓取特定平台（如：欧美抓取 X/Reddit，中国抓取微博/小红书，中东抓取 Al Jazeera/X，南美抓取 Instagram/Telegram）。

信噪比过滤： 自动剔除广告和低质量复读，只提取核心叙事（Original Narratives）。

功能 2：深度引爆引擎 (优化：引入“情绪分布”与“传播路径”)
优化点： 不只分析原因，还要分析**“情绪燃料”**。

细化：

引爆因子拆解： 将原因归类为：突发事件驱动、KOL点火、算法推荐、还是文化共鸣。

情绪光谱： 展示该事件在当地引发的情绪（愤怒、狂欢、恐惧、好奇）。

核心引爆点识别： 标注出第一个把该话题推向热搜的账号或媒体。

功能 3：跨地区对比分析 (新增：差异化洞察)
优化点： 比较同一个事件在不同地区的看法。

场景： 比如“川普言论”，在欧美是政治博弈，在东亚可能是经济预警。这种对比是极高价值的输出。

功能 4：一键分析与多格式导出 (优化：不仅是保存)
优化点： 支持一键生成**“简报（Report）”或“播客/短视频脚本”**。

细化： 支持保存为 Notion 页面、Markdown 或带有可视化图表的 PDF。

3. 流程图与交互设计 (你的核心关切点)
我们要让用户像“刷抖音”一样简单地获取“专业情报”。

3.1 交互逻辑：由面到点，渐进式呈现
第一层：全球概览 (The Map)

视觉： 一个可交互的世界地图或 7 个色块。色块的大小代表该地区近三天的舆论热度。

操作： 点击中国区，直接进入中国区的热点列表。

第二层：事件流 (The Feed)

视觉： 类似卡片流。每张卡片包含：标题、核心热度、一句话总结、主要来源图标。

操作： 向上滑动切换事件，向右滑动进入“深度分析”。

第三层：深度分析页 (The Deep Dive)

视觉： 左侧为事件时间轴，右侧为 AI 生成的“引爆分析图谱”。

操作： 点击“Compare”按钮，横向对比其他地区对此事的观点。

3.2 用户路径流程图 (User Flow)
[进入APP] -> [全球热力图看板] -> [点击特定区域] -> [浏览事件卡片] -> [点击一键分析] -> [查看引爆原因/观点对比] -> [点击保存/分享]

4. 技术实现路线图 (我如何帮你构建它)
既然我已经演示了**“智能层”，下面是构建这个软件的“工程层”**方案：
4.1 核心架构设计
数据采集层 (The Tentacles):
工具: Python (Scrapy/Selenium), 官方API (X Enterprise API, Reddit API), RSS Hub (针对媒体)。
难点: 微博/小红书/TikTok的反爬虫。需使用代理池 (Proxy Rotation) 和 OCR技术 (读取图片中的文字)。
智能处理层 (The Brain - 我的角色):
翻译与清洗: 使用轻量级模型 (如 gpt-4o-mini 或 DeepSeek) 进行多语言实时翻译。
叙事提取: 利用 LLM 进行 Clustering (聚类分析)，将成千上万条推文归纳为 3 个核心观点。
情绪光谱:使用 NLP 情感分析库 (VADER 或 Bert) 标注情绪色谱。

4.2 应用层 (The Face):
前端: Flutter (确保iOS/Android双端一致，且动效流畅)。
地图交互: Mapbox GL JS (支持自定义色块和高性能渲染)。
自动化报告 (The Output):
功能: 利用 LangChain 调用 LLM，将结构化数据（JSON）转化为 Markdown/Notion 格式，甚至通过 TTS (语音合成) 生成播客脚本。
